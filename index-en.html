Simple guide

You can think of the tool this way:

Characters
Create or edit heroes: Guardian, Cartographer, Mystic, Poacher or any other characters.
Catalogs
Enter everything that can be used in play: items, weapons, armor, artifacts, potions, scrolls, spells, abilities, allies, mercenaries and animals.
Dashboard
Manage the session: choose the 4 heroes, assign items, activate effects, use abilities and check Body, Mind, Attack, Defense and Movement.

Move the 4 active characters to another file

This section exports only the party selected in the Dashboard to another file. It is not a full tool backup.

Session data: not filled in. You can edit it in the Dashboard; it will be included in the active-party file and printout.
1. Save everything
Before loading data into an important file, click “Save database”. This is the full backup: it contains everything.
2. Save only the 4 active heroes
Creates a file with the party shown in the Dashboard: the 4 heroes, their inventory, effects, allies and abilities.
3. Load the 4 active heroes
Loads that party into this tool. Other characters and existing catalogs remain in place.
This active-party file does not delete everything. However, if it finds the same existing character, it updates it and replaces its inventory, effects, allies and abilities with those from the loaded file.

Regola di sicurezza

Modalità predefinita: nessun oggetto esistente viene modificato.
Il catalogo attuale resta intatto: gli oggetti importati vengono aggiunti solo se hanno un ID nuovo. Gli ID già presenti vengono saltati, salvo scelta esplicita diversa.
Consigliato prima di import grandi o aggiornamenti.

Handling existing IDs

Il confronto che può modificare un oggetto esistente avviene solo sull'ID. Il nome uguale viene segnalato come possibile doppione, ma non causa sovrascrittura automatica.
Questa spunta serve solo per la modalità “Aggiorna”. Senza questa autorizzazione, l'app blocca l'import se dovrebbe modificare oggetti esistenti.
