# Hero Dashboard
## Open the app / Apri l'app

- Versione italiana: https://thunajack.github.io/hero-dashboard/
- English version: https://thunajack.github.io/hero-dashboard/index-en.html
  
## Italiano

**Hero Dashboard** è uno strumento fan-made gratuito per uso personale, pensato per gestire eroi, inventari, effetti, abilità, alleati e salvataggi in campagne dungeon crawler/fantasy.

Il progetto è distribuito come interfaccia vuota/personalizzabile con dati demo fittizi. Non include testi ufficiali di carte/manuali, immagini, loghi o database ufficiali già compilati.

### Avvio rapido

- Apri `index.html` per la versione italiana.
- Apri `index-en.html` per la versione inglese.

### Dati e privacy

I dati vengono salvati localmente nel browser dell'utente. L'autore non riceve, non raccoglie e non conserva i database creati dagli utenti.

Usa spesso **Salva database** per creare un backup JSON.

### File principali

- `index.html`: interfaccia italiana.
- `index-en.html`: interfaccia inglese.
- `demo/`: database e CSV dimostrativi con dati fittizi.
- `docs/guida-uso-it.txt`: guida utente in italiano.
- `docs/user-guide-en.txt`: user guide in English.
- `LICENSE.txt`: condizioni d'uso.
- `NOTICE.txt`: note su copyright, privacy e contenuti ufficiali.

## English

**Hero Dashboard** is a free fan-made tool for personal use, designed to manage heroes, inventories, effects, abilities, allies and backups in dungeon crawler/fantasy campaigns.

The project is distributed as an empty/customizable interface with fictional demo data. It does not include official card/manual text, images, logos, or pre-filled official databases.

### Quick start

- Open `index.html` for the Italian version.
- Open `index-en.html` for the English version.
- To publish it online with GitHub Pages, choose which version should be your main page. You can keep `index.html` as the Italian home page and link `index-en.html` as the English version.

### Data and privacy

Data is stored locally in the user's browser. The author does not receive, collect, or store databases created by users.

Use **Save database** often to create a JSON backup.

### Main files

- `index.html`: Italian interface.
- `index-en.html`: English interface.
- `demo/`: demo database and CSV files with fictional data.
- `docs/guida-uso-it.txt`: Italian user guide.
- `docs/user-guide-en.txt`: English user guide.
- `LICENSE.txt`: terms of use.
- `NOTICE.txt`: copyright, privacy and official-content notes.
